# SAI Theme

This is THE ONLY open source code for public use, for now.
Custom themes for VS Code with Roboto SAI color schemes.

## Themes Included

- **SAI Fuego**: A dark theme with Roboto-SAI-Fuego colors featuring green accents
- **SAI Light**: A light theme with clean, professional colors

## Installation

The themes are automatically included with SAI Code. To activate:

1. Open VS Code
2. Go to File > Preferences > Color Theme
3. Select "SAI Fuego" or "SAI Light"


## Features

- **Gold** and **Red** accents for a vibrant look
- Optimized for Fuego theme
- Consistent color palette
- Support for all major programming languages
- Terminal and UI theming
